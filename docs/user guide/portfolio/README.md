# Learn How to Use the Template Portfolio Application

## Features

The Template Portfolio Application provides capabilities to upload, import, and view model data on Twinit, and to work with portfolio data (sites and buildings) on a map. Features include:

* **Importing model representations (BIMPKs)**. The application supports viewing and importing model representations (bimpks) uploaded to the project. You can import models for use in the portfolio map and in the model viewer.
* **Viewing models in 2D and 3D**. View any version of imported models in the project with 2D and 3D views, cutting planes, and view modes.
* **Portfolio map**. View sites and buildings on a Mapbox-backed map. Use the status bar chart and search filters (Status, Group, Facility Location) to filter what you see.
* **Model comparison**. Compare two models side by side with search, filters, and element property views.
* **Viewing model element properties**. Select elements in the model viewer or in the comparison table to view instance and type properties. Use search and filters to find elements.
* **Managing and viewing files**. Admins can upload files and associate them to models; users can download or view them in the browser where supported.
* **Inviting users**. Use the application’s User Groups page to invite users to participate in Template Portfolio projects.

## User Groups

Feature access is controlled by the User Group to which a user belongs. Projects created from the template use:

* **Admin** – Uses **PortfolioAdminConfig**; full permissions (config, import, files, Mapbox, invite users).
* **Viewer** – Uses **PortfolioViewerConfig**; read-only access to view models, map, and portfolio data (Portfolio Overview opens by default).

Exact permissions depend on how your project is configured.

## Getting started

* Sign in to the Template Portfolio application and open a project.
* Use the **Portfolio** view to see sites and buildings on the map, and use the status chart and filters to explore by status, group, or facility.
* Use the **Model** views to import and view models, and to compare two models and inspect element properties.
