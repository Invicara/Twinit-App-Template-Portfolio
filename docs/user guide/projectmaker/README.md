# Learn How to Use the Portfolio Manager

![project maker](../../img/proj-make-complete.jpg)

## Features

* **Create new Portfolio projects**. Using the Portfolio Manager you can quickly and easily create new Portfolio projects.
* **Update existing projects to the latest version**. When new template versions are available, update your projects to take advantage of the latest features.

## User Groups

Portfolio Manager projects have one User Group:

* QMV Managers

Users in the **QMV Managers** user group have full permissions to all resources in the Portfolio Manager project.
